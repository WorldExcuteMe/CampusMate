## 范围

本批基于最新 `origin/develop`（与核查时 main 的代码树一致），通过个人 Fork 分支提交到原仓库 develop，不直接推送或合并 main/develop。

1. **真实业务落库**：服务端通知、日常任务、成长目标、通知合并接入 Postgres，沿用前端业务表、owner 隔离、幂等与事务；未配置存储或写入失败不口头报成功。
2. **DeepSeek 与工具协议**：原生工具/思考能力接线；思考续传信息仅留服务端并绑定供应商/模型，不进入公开消息 API。DSML 等未解析工具正文失败关闭，不重放旧错误操作。消息支持复制与编辑后以新轮次重发。
3. **会话同步**：同账号、同后端恢复完整对话，名称/模式/归档/恢复/删除落库，元数据版本冲突拒绝覆盖，删除墓碑防旧缓存复活。旧本地历史备份后只读导入，不重放工具。
4. **文档导出**：安装与自检脚本，产品/探针使用相同固定 Chromium channel，保留沙箱；实际生成并复读中文、跨页表格、图片、图表 DOCX/PDF。错误明确报出，不伪报文件可下载。
5. **工具恢复与检索**：机会未知截止日期接受 null/省略/空值；同操作真实成功重试可以解除失败，不同目标/格式及不确定副作用不能冲掉错误。模型可达和工具完成分别验收。检索过滤明显无关结果、检查 HTTP/解析和质量提醒，搜索线索仍须核对官网正文。
6. **草稿保护**：文字、附件、解析中的原始 File 和名称编辑按账号/会话留在本机 IndexedDB；重试旧轮次不吞新草稿。多标签写入使用事务内 CAS，冲突两份均保留，可选择/恢复；发送、名称提交先校验版本，删除墓碑阻止复活，旧稿加性迁移到统一后端会话标识。
