## 核验报告/依据原子保存 · 2026-11-14

- **先复现**：原实现仅检查报告 insert，忽略 evidence_items insert 返回的 error。新增 9 项 Repository 契约断言在修改前出现 8 个失败，包括依据拒绝仍 resolve 成功。另补聊天关键保存失败阻断测试，最终新增 web 测试共 10 项。
- **数据库事务**：新增 `supabase/migrations/0003_atomic_verification_reports.sql`，定义 SECURITY INVOKER / 空 search_path 的 save_verification_report(jsonb)。父报告与依据在一次调用事务内保存，不捕获子 insert 异常掩盖失败。相同 ID + 同内容可幂等重试（依据顺序/等价时间格式不影响），内容不同则拒绝，不覆盖历史。返回数据库实际报告、依据和时间，不返回客户端假定保存结果。

- 不启用 raw HTML；代码块按文本展示；URL 经过公开 http(s) 校验，不允许可执行协议/本地文件/相对 API 路径/带凭据地址；外链新窗口隔离。模型 Markdown 图片只显示占位，不自动请求远端地址。清单复选框只读，不修改业务任务。
- 表格/代码块在消息区域内独立横向滚动，手机布局不被长内容撑宽。渲染组件 memo 化，输入框或进度更新不重复解析不变的旧回复。新增解析依赖位于懒加载聊天页，主包仍约 636KB（既有 >500KB 警告），聊天 chunk 约 225KB。
- 新增 4 单测（排版、原始 HTML/图片、危险链接、只读清单）+1 E2E（历史/新回复、用户原文、存储不变、手机表格、无远端图片请求）。web 147/147、全量 E2E 15/15、build 通过；用户入口 5173 上另跑本项 E2E 通过。已查看桌面/手机实际截图 test-results/agent-markdown-desktop.png、agent-markdown-mobile.png。网络内容使用 fixture，未调用付费模型或修改用户当前浏览器存储。
