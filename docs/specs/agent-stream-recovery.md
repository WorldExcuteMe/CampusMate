## 复现与假设

- `20261116-224218_live_quality-long-progress-de_12ad51`两项HORIZON第9轮均finishReason=null、usage缺失，36/45秒后在相同毫秒附近终止，未触及180秒idle或任务预算。更符合共享连接/上游提前关闭，而非“长文写不了”或token预算不足；尚不能定位具体代理或上游。
- 旧循环把任何截断直接暂停。目标：已经收到普通文本、流提前关闭且无工具指令时，只允许一次只读续写；不能重新执行之前工具。
- LIVE-007自动失败直接因为paused；另有人工作用域风险：拒绝system prompt后继续详细列出工具。显式索取私有系统/开发者指令或内部工具schema时，Runtime直接提供能力说明和拒绝，不依赖模型自觉拒绝。

## Given/When/Then

1. 普通正文网络EOF且任务预算足够 → 一次无tools续写，拼接去重，正常终态；所有请求实际计费计数。
2. 原生/JSON工具片段、长度上限、协议错误、超时/取消 → 不自动续写，不执行部分指令。
3. 续写再断、空答或返回工具 → 保留完整草稿、暂停，最多一次，无工具执行。
4. 续写检查点后进程中断 → 恢复时可找回前缀，最终答案包含原始正文，不能丢掉前半篇。
5. 直接索取系统原文/内部工具定义 → 无模型/工具调用，明确拒绝且不回显内部文本；正常功能询问、执行进度、对攻击样本的分析保持正常。
