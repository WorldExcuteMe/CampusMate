## 契约 / 影响

- runtime/sql.ts：查询和事务统一先取得连接；仅已识别的临时建连失败最多尝试两次，尚未发送 SQL。代理连接允许 15s，直连保持 8s；明确有限超时。空闲保留 60s、TCP keepalive，监听池空闲连接错误。
- 默认 SQL、事务回调、COMMIT 不重试；经调用点审阅并显式使用 readQuery 的纯只读查询，允许中途断线后重试一次。transactionPool 不带此能力，事务内部读取不重放。回滚失败保留原错误并丢弃坏连接；鉴权、证书、SQL及代理授权错误直接报错。
- core/errors.ts、agent-loop.ts、runtime/worker.ts：建连恢复耗尽归为存储中断，保留检查点并暂停，不能伪装模型不可达或成功。暂停前核验 worker/attempt/lease，避免覆盖新执行者。心跳存储异常也保留存储原因。
- app-context.ts、.env.example：可选有界 DATABASE_CONNECTION_TIMEOUT_MS，默认无需用户配置。主密钥、TLS 校验和工具幂等不变。
