# CampusMate 前端 Agent UI 整合设计（2026-11-19）

> 依据：用户整合要求（单窗口、会话分组、工作台右栏、工具卡片、附件工作流卡、只读任务简化、设置/技能/MCP 同窗管理）、
> DSH 前端参考（`docs/specs/frontend-agent-ui-dsh-reference.md`）、前端审计（`frontend-agent-ui-audit.md`）、
> 后端 API 缺口审计（`frontend-agent-ui-api-gaps.md`）。所有界面元素必须绑定真实数据/接口；后端未就绪的能力一律
> **隐藏或 feature-flag**，不做死按钮。

## 1. 布局：一个窗口三层

```
┌──────────────────────────────────────────────────────────────────────────┐
│ AppShell（唯一窗口）                                                       │
│ ┌───────────────┬───────────────────────────────┬──────────────────────┐ │
│ │ 左：导航+会话  │ 中：对话（唯一滚动区）           │ 右：任务工作台        │ │
│ │ 280px          │ header: 标题/模型/操作           │ Tabs: 工作步骤/产物/  │ │
│ │ · 导航入口     │ 消息流（Markdown/工具卡/思考）    │ 上下文               │ │
│ │ · 最近会话(≤20)│ 附件工作流卡                     │ （无工作内容时隐藏）  │ │
│ │ · 已完成会话   │ composer（+ / 权限 / 模型 / 思考）│                      │ │
│ │   （折叠）     │ 状态条（上下文仪表 + 统计药丸）   │                      │ │
│ └───────────────┴───────────────────────────────┴──────────────────────┘ │
│ 设置/技能/MCP：同窗口路由页（/app/settings 等），带返回；不弹外链。         │
└──────────────────────────────────────────────────────────────────────────┘
```

- **单窗口**：所有页面在既有 `Layout` 内路由，设置、技能、MCP 管理都是同一窗口内的页面/抽屉，不跳外站。
- **左栏会话分组**：最近会话最多 20 条（按本地更新时间倒序）；已完成（归档）会话折叠成一组，可移回/删除；
  每行 hover 出现"标记完成/删除"；保留"新会话"按钮。
- **右栏工作台**：三个标签页——工作步骤（工具调用卡片、审批、预算、错误）、产物（文档预览/下载）、
  上下文（占用/首 token/轮次步数/缓存/token/费用/压缩状态）。**只读/纯问答任务不渲染右栏**（无工具、无产物、无审批时隐藏）。
- **composer 保留**：`+` 附件、权限选择（左下）、模型切换、思考强度；附件以"附件工作流卡片"呈现（解析状态/移除/随后发送）。

## 2. 对话时间线（消息区）

| 节点 | 展示 | 折叠规则 |
| --- | --- | --- |
| 用户消息 | 右对齐气泡，可编辑重发 | 常显 |
| 助手回复 | Markdown（表格/链接安全），复制 | 常显 |
| 思考/推理 | 默认折叠的"思考"行，运行中显示首行 shimmer；完成后首行预览 | 由"工作步骤展示"密度决定（精简/标准/详细/完整） |
| 工具调用卡片 | 每 callId 一张卡：图标+中文动作+状态点+耗时+结果摘要；终端命令显示命令与退出码 | 卡片内折叠；失败红点/恢复中黄点 |
| 压缩/截断 | 上下文标记行："已压缩 N 条历史（约 X tok）" | 可展开 |
| 审批 | composer 变为审批卡（批准/拒绝/风险说明） | 常显 |
| 错误/预算 | 行内错误/暂停卡，附恢复/调整预算操作 | 常显 |
| 产物 | 文档卡片（预览/下载 md/docx/pdf） | 常显（产物 tab 同步） |

**展示设置**（已落地三控件，对应 DSH 的 `transcriptView` / `collapseTiming` / `foldedReplies`）：
`工作步骤展示 = 精简/标准/详细`；`收起时机 = 回答结束后/立即/手动`；`收起后回复 = 全部/仅最终/不显示`。
后续补"完整展开"第四级，与 DSH 对齐。

## 3. 状态条（composer 下方）

- **上下文仪表**：图标 + `xx%` + `used/limit` + 累计 token + 缓存命中 + 首 token 延迟 + `N 轮 M 步`；
  tooltip 展示模型上限、最近请求输入/输出/思考 token、费用、压缩/截断；点击可展开分层明细（系统/工具/消息）。
- **数据来源**：`task.promptUsage`、`task.modelRuntime.lastRequest`、事件流计数；无数据显示"未知"，不估算占位。
- **待后端**：session 级缓存聚合、上下文分层 breakdown（需 `/v1/settings` 与估算接口），UI 预留字段、隐藏为"—"。

## 4. 设置 / 技能 / MCP（同窗管理）

| 页面 | 现状 | 后续 |
| --- | --- | --- |
| 模型供应商 | 已有列表/添加/测试/默认/删除；容量预设 128K/200K/256K/500K/1M | 后端补模型目录、保存前探测、单条 GET；每模型 reasoning 档位与输入能力 |
| Agent 设置 | 外观/工作步骤三控件已落地；语言、预设入口已有 | 独立"Agent 设置"tab：默认模型/思考默认值/权限默认/工作步骤默认/工作区 |
| 技能管理 | 前端无入口 | 后端 `/v1/skills`（列表/启停/删除/查看 SKILL.md）+ 前端页面；内置技能只读、自定义技能可删 |
| MCP 管理 | 前端无入口 | 后端 MCP client（连接/工具命名空间/审批继承）+ `/v1/mcp/servers` CRUD；前端页面展示连接状态与工具，可禁用/删除 |
| 工作区 | 本地工作区连接/权限已存在 | 云端工作区列表/切换；文件树 + 文档预览（需 `/v1/workspace/files`） |

**原则**：后端未提供的接口不渲染入口（或 feature-flag 且标注"即将开放"但不交互）。

## 6. 脑洞清单（超出用户点名、低成本优先）

1. 会话搜索 + 命令面板（⌘K）；2. 每轮"交付物卡"汇总文件/链接；3. 轮次导航条（跳到某轮）；4. 排队消息（Queue/Steer）；
5. 斜杠命令（/new /compact /model /stop）；6. @ 引用工作区文件；7. 会话导出（md/json + trace）；
8. 成本/预算进度条与"本次花费"；9. 思考摘要开关（隐私默认关）；10. 空状态引导（模板任务）；
11. 键盘 Esc-Esc 停止、Enter/Shift+Enter；12. 右侧面板可拖拽宽度/全屏；13. 附件拖拽排序与重试；14. 离线/断网状态条；
15. 工具调用时间线折叠成"12 步、用时 34s"摘要（DSH turn-process）。
